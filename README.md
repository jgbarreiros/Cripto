# Cripto
🔐 Cripto
📌 Português
🧩 Descrição

Cripto é um aplicativo desenvolvido em Python para criptografia e descriptografia de mensagens e arquivos, utilizando criptografia simétrica.
O projeto tem como objetivo fornecer uma ferramenta simples, segura e intuitiva para proteger informações sensíveis.

A interface gráfica é construída com CustomTkinter (ctk), enquanto os recursos criptográficos são implementados com a biblioteca cryptography.

⚙️ Funcionalidades

🔒 Criptografia de mensagens de texto

📂 Criptografia de arquivos

🔑 Uso de criptografia simétrica (mesma chave para criptografar e descriptografar)

🖥️ Interface gráfica amigável

🐍 Desenvolvido inteiramente em Python

🛠️ Tecnologias Utilizadas

Python 3

CustomTkinter (ctk) – Interface gráfica

cryptography – Implementação de criptografia segura

📚 Observações

Este projeto tem fins educacionais e demonstra o uso de criptografia simétrica em aplicações Python.
Para uso em produção, recomenda-se uma análise de segurança mais aprofundada.

📌 English
🧩 Description

Cripto is an application developed in Python for encrypting and decrypting messages and files using symmetric cryptography.
The goal of the project is to provide a simple, secure, and intuitive tool to protect sensitive information.

The graphical interface is built with CustomTkinter (ctk), while cryptographic features are implemented using the cryptography library.

⚙️ Features

🔒 Text message encryption

📂 File encryption

🔑 Symmetric cryptography (same key for encryption and decryption)

🖥️ User-friendly graphical interface

🐍 Fully developed in Python

🛠️ Technologies Used

Python 3

📚 Notes

This project is intended for educational purposes and demonstrates the use of symmetric cryptography in Python applications.
For production use, a more in-depth security review is recommended.

CustomTkinter (ctk) – Graphical interface

cryptography – Secure cryptographic implementation
